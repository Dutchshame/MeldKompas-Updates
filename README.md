# MeldKompas Updates

Deze openbare repository bevat uitsluitend bestanden voor MeldKompas-releases.
De applicatiebroncode wordt hier niet gepubliceerd.

## Bestanden in een release

- `latest.yml`: versiemetadata die MeldKompas bij het opstarten controleert.
- `MeldKompas Setup <versie>.exe`: de Windows-update-installer.
- `.blockmap`: helpt de updater downloads efficiënter te verwerken.

Testbuilds blijven lokaal. Alleen goedgekeurde full releases worden hier als
GitHub Release geplaatst.
